# Medios del proyecto

Creación: 23 de octubre de 2026.

- `josemi-os-demo.mp4`: grabación real de la interfaz con Playwright. Se muestra una orden local de Milo, la entrada de Arcade y el contacto; no se simulan respuestas de una API ni un proceso de programación inexistente.
- `demo-poster.png`: captura de la misma sesión, 1280×720.
- `demo-es.vtt`: subtítulos descriptivos en castellano. El vídeo no tiene audio.
- `demo-transcripcion.html`: alternativa escrita del recorrido.

Codificación final: FFmpeg 9.0.2, H.264/libx264, CRF 26, yuv420p, 25 fps, 30 segundos y `+faststart`. Tamaño: 1.155.953 bytes. Se comprobó la reproducción completa, el salto a distintos puntos, los controles, la pausa al minimizar y la adaptación a pantallas de 320, 390 y 768 píxeles. La captura y el vídeo son medios del proyecto, no una fotografía personal.

Herramientas: [grabación con Playwright](https://playwright.dev/docs/videos), [FFmpeg](https://www.ffmpeg.org/download.html). Las herramientas no forman parte de los archivos publicados de la web.
