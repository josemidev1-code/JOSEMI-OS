# Fuentes tipográficas

## Fuentes activas

- **Atkinson Hyperlegible Next**: interfaz, títulos y texto. Archivo variable procedente del [repositorio oficial de Google Fonts](https://github.com/google/fonts/tree/main/ofl/atkinsonhyperlegiblenext). `atkinson-next.ttf` se ha convertido a WOFF2 con FontTools, conservando sus glifos. Licencia: `OFL-Atkinson-Next.txt`.
- **JetBrains Mono**: terminal, código y ASCII. WOFF2 original del [repositorio de JetBrains](https://github.com/JetBrains/JetBrainsMono/tree/master/fonts/webfonts). Licencia: `OFL-JetBrains-Mono.txt`.

Se sirven desde esta carpeta, sin peticiones a servicios de fuentes externos. Las variables y declaraciones de fuente están centralizadas en `styles/typography.css`. Las ligaduras se desactivan en código y ASCII para conservar la distinción de caracteres.

## Versiones anteriores

Pixelify Sans y VT323, con sus archivos y licencias OFL, pertenecen al diseño anterior y se mantienen como recursos históricos. La interfaz actual utiliza las dos fuentes indicadas arriba.
